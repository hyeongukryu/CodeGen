# code-gen-example

To install dependencies:

```bash
bun install
```

To type-check the example and generated SDK with TypeScript 7:

```bash
bun run typecheck
```

To run (with the .NET example server listening on port 5000):

```bash
bun run start
```

This project was created using `bun init` in bun v1.3.14. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
